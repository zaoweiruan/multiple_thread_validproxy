请优化这个 Windows 10 Win32 桌面弹窗的 UI 配色，不改变现有布局、控件位置、功能和交互逻辑，只调整视觉风格。

整体风格：
- 保留 Windows 10 原生桌面应用的简洁、克制、专业感
- 不要做成 Windows 11、Material Design、Web UI 或深色主题
- 避免过度圆角、渐变、玻璃效果和大面积阴影
- 使用浅色背景，以白色、浅灰、Windows 蓝作为主要色彩体系
- 整体减少目前大量中灰色造成的“旧式 Win32 软件”观感

配色建议：
1. 主窗口背景：
   - 使用 #F5F6F7 或 #F3F4F6
   - 不要使用明显的深灰背景

2. 表格/列表区域：
   - 内容区域使用 #FFFFFF
   - 表头使用 #F3F4F6
   - 表头文字使用 #323130
   - 普通文字使用 #202020
   - 次要文字使用 #605E5C

3. 表格分隔线：
   - 使用非常浅的 #E1E1E1
   - 降低目前明显灰色竖线的视觉存在感

4. 选中状态：
   - 使用 Windows 风格蓝色，例如 #0078D4
   - 选中行背景可以使用非常浅的蓝色 #E5F1FB
   - 选中文字保持深色或使用 Windows 蓝色体系
   - 不要使用饱和度过高的纯蓝色

5. ScrollBar：
   - 滚动条轨道使用 #F1F1F1
   - 滑块使用 #C8C8C8
   - 鼠标悬停时可变为 #A6A6A6
   - 不要使用现在这种大面积深灰色滚动条背景
   - 滚动条滑块可以保留 Windows 10 原生的矩形风格

6. Slider / Trackbar：
   - 保持 Windows 10 原生控件风格
   - 轨道使用浅灰色
   - 当前进度/激活部分使用 #0078D4
   - 滑块使用 Windows 蓝色
   - 不要使用亮度过高的纯蓝色

7. 边框：
   - 使用 #D1D1D1 或 #DADADA
   - 边框尽量细、低对比度
   - 不要使用明显的深灰粗边框

8. 强调色：
   - 整个窗口只使用一种主强调色：Windows 蓝 #0078D4
   - 蓝色只用于选中状态、Slider、焦点状态和重要交互
   - 不要出现多个不同的蓝色

目标视觉风格：
Windows 10 Fluent Design 风格的轻量化桌面工具。
整体以 #FFFFFF、#F5F5F5、#EDEDED 为基础色，
以 #0078D4 作为唯一强调色。

视觉层级从上到下：
窗口背景 → 表格白色区域 → 浅灰表头 → 浅灰分隔线 → 深色文字 → 蓝色交互状态。

要求整体干净、轻盈、低饱和、低阴影、低装饰。
不要追求炫酷，而是追求专业、稳定、易读。
