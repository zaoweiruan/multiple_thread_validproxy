请针对当前 Windows 10 Win32 桌面程序界面进行整体配色优化。

不要修改窗口布局、控件尺寸、表格列宽、功能、交互逻辑和数据内容。
只优化颜色、视觉层级、选中状态、边框、背景和控件视觉效果。

整体设计目标：
- 保留 Windows 10 原生桌面软件的感觉
- 风格定位为：专业、简洁、高信息密度、轻量现代化
- 不要做成 Windows 11 风格
- 不要使用 Material Design
- 不要使用大圆角
- 不要使用渐变
- 不要使用玻璃/透明效果
- 不要使用大面积阴影
- 不要做成网页 UI
- 重点改善当前界面“大量灰色堆叠”的问题

【Toolbar 工具栏】

当前工具栏存在较多灰色背景和图标视觉重量过大的问题。

优化为：
- 工具栏背景使用 #FFFFFF
- 不要使用大面积灰色背景
- 工具按钮默认透明/白色
- 鼠标悬停使用 #F3F6F9
- 按下状态使用 #E5F1FB
- 选中/激活状态使用 #0078D4
- 图标保持原来的尺寸和位置
- 图标之间适当增加视觉间距
- 不要给每个按钮增加明显边框

【最终视觉效果】

目标不是“重新设计一个界面”，而是在当前 Win32 UI 基础上做一次专业级配色升级。

最终效果应该接近：

Windows 10 原生工具
+
现代化的数据表格
+
轻量 Fluent 配色
+
高信息密度开发工具

整体感觉：
干净、专业、稳定、清晰。

尤其要解决以下问题：

1. 当前大量 #808080/#A0A0A0 灰色造成的老旧感
2. Toolbar 与内容区域层级不明显
3. 表格边框过于明显
4. 左侧列表选中状态不突出
5. 日志区域与主表格视觉割裂
6. Status Bar 视觉重量过大
7. 蓝色没有形成统一的 Accent Color

请统一使用 Windows Blue #0078D4 作为整个程序唯一主要 Accent Color。
- 不要为了现代化而降低信息密度。
- 不要增加卡片、圆角、留白和装饰元素。
- 优先保证表格数据的可扫描性。
- 颜色只用于表达层级和状态，而不是装饰。
